Not too long ago, I looked into how different classes of container escapes worked, and how to detect them using the [auditd framework](https://www.man7.org/linux/man-pages/man8/auditd.8.html).
This series of posts covers the 4 main escape types I looked into: namespace modifications, SSH credential reuse, Docker socket abuse, and host volume mounts.

Within each page, I've also included some basic `auditd` syscall logs as examples,
and some advice for paring down the huge volume of data you are likely 
to see when casting a wide net like this.

## Auditd Rules

In order to perform these tests, I reused some fairly broad Auditd rules from the official GitHub repository:

[https://github.com/linux-audit/audit-userspace](https://github.com/linux-audit/audit-userspace)

Specifically, I focused on rules found in `11-loginuid.rules` and `41-containers.rules`.

```sh
$ cat /etc/audit/audit.rules
## This file is automatically generated from /etc/audit/rules.d
-D
-b 8192
-f 1
--loginuid-immutable
-a always,exit -F arch=b32 -S clone -F a0&0x7C020000 -F key=container-create
-a always,exit -F arch=b64 -S clone -F a0&0x7C020000 -F key=container-create
-a always,exit -F arch=b32 -S unshare,setns -F key=container-config
-a always,exit -F arch=b64 -S unshare,setns -F key=container-config
--backlog_wait_time 60000
-a never,exclude -F msgtype=CRED_ACQ
-a never,exclude -F msgtype=CRED_DISP
-a never,exclude -F msgtype=CRED_REFR
-a never,exclude -F msgtype=USER_END
-a never,exclude -F msgtype=USER_START
-a never,exclude -F msgtype=USER_ACCT
-a never,exclude -F msgtype=USER_CMD
-a never,exclude -F msgtype=CHUSER_ID
-a never,exclude -F msgtype=CHGRP_ID
-a never,exclude -F msgtype=SOCKADDR
-a always,exit -F arch=b32 -S execve -S execveat -k process_creation
-a always,exit -F arch=b64 -S execve -S execveat -k process_creation
-a always,exit -F arch=b64 -F path=/tmp/breakout_test.txt -F perm=rwxa -F key=breakout_file
```
